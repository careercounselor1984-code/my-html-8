GoodJob Career Hub 개인정보처리방침

GoodJob Career Hub는 취업·복지·창업 상담을 지원하기 위해 공공 및 연계 데이터를 검색하는 상담지원 API입니다.

1. 처리 목적

사용자가 입력한 상담 조건을 바탕으로 채용정보, 복지정책, 창업지원사업 등 관련 정보를 검색하고 상담 참고자료를 제공하기 위해 정보를 처리합니다.

2. 처리할 수 있는 정보

나이, 지역, 취업상태, 희망직무, 창업단계, 관심 지원분야, 검색어 등 사용자가 직접 입력한 최소한의 상담조건이 처리될 수 있습니다.

3. 민감정보

주민등록번호, 계좌번호, 비밀번호, 상세주소 등 불필요한 민감 개인정보를 요구하지 않습니다.

4. 외부 데이터 및 API

ALIO, 클린아이, 공공 복지정보, K-Startup 등 공공·연계 데이터 소스를 조회할 수 있으며, 필요한 경우 Supabase Edge Function을 통해 외부 API와 통신합니다.

5. 저장 여부

사용자가 GPT 또는 웹에서 입력한 일반 상담조건을 별도의 이용자 프로필 데이터베이스에 영구 저장하는 것을 목적으로 하지 않습니다. 외부 API 인증키는 이용자에게 노출되지 않도록 서버의 보안 저장소에서 관리합니다.

6. 제3자 제공

사용자 정보를 광고 또는 마케팅 목적으로 판매하거나 제공하지 않습니다. 검색 수행을 위해 필요한 범위에서 해당 외부 데이터 서비스와 요청 정보가 처리될 수 있습니다.

7. 결과의 성격

제공되는 결과는 상담 참고용입니다. 채용 지원 가능성, 복지 수급자격, 창업지원사업 신청·선정 가능성을 확정하지 않으며 각 기관의 최신 공식 공고와 세부 요건을 최종 확인해야 합니다.

8. 문의

개인정보처리 관련 문의는 서비스 운영자에게 문의할 수 있습니다.
