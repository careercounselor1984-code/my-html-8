좋은일자리 채용 지원전략 AI 설정 가이드

채용 지원가능성 분석센터 v1.8과 연결할 전용 Custom GPT를 만드는 설정값입니다. 기존 사이트 판정 로직은 건드리지 않고 GPT는 지원전략 상담만 담당합니다.

설정 순서

1
ChatGPT 웹에서 GPT 만들기
GPTs → 만들기 → 구성 화면으로 들어갑니다.
GPTs 열기
2
아래 이름·설명·지침·대화 시작 문구 입력
복사 버튼을 눌러 그대로 붙여넣으면 됩니다.
3
Actions → 새 작업 만들기
인증은 없음(None), 스키마는 아래 URL에서 가져오거나 내용을 붙여넣습니다.
4
미리보기에서 테스트 후 만들기/업데이트
공개 범위를 링크 공유 이상으로 설정하려면 Action의 개인정보처리방침 URL도 입력합니다.
5
생성된 GPT 공개 URL 복사
채용 지원가능성 분석센터의 '전용 GPT URL 설정'에 한 번 붙여넣으면 이후부터 바로 연결됩니다.

기본 정보

이름

좋은일자리 채용 지원전략 AI

설명

채용 지원가능성 분석센터의 판정결과를 바탕으로 지원전략, 부족역량, 자기소개서, 면접준비를 돕고 필요 시 현재 채용공고와 유사 직무를 추가 검색하는 취업상담 AI입니다.

대화 시작 문구

이 지원가능성 분석결과를 보고 지금 지원전략을 짜줘. 내 조건에 맞는 현재 채용공고를 울산 중심으로 찾아줘. 이 공고 기준으로 자기소개서에서 뭘 강조해야 할지 알려줘. 이 직무 면접에서 나올 만한 질문 5개와 답변 방향을 만들어줘.
